Основание

Билл Гейтс и Пол Аллен создали компанию 4 апреля 1975 года в Альбукерке. Изначально название писалось через дефис — Micro-soft, объединяя слова «микрокомпьютер» и «software»

Первый успех

Друзья разработали интерпретатор языка BASIC для одного из первых ПК — Altair 8800. Продажи этого продукта оправдали ожидания и заложили финансовый фундамент компании.

Сделка с IBM

Ключевым моментом стал контракт с IBM. Microsoft купила права на операционную систему 86-DOS у другой компании, доработала её и лицензировала IBM как MS-DOS. При этом Гейтс сохранил право продавать ОС другим производителям, что сделало Microsoft доминирующим игроком на рынке ПК.

Публичная компания

В 1986 году Microsoft вышла на биржу (IPO), что мгновенно превратило Билла Гейтса в одного из самых богатых людей мира.

Наши преимущества

1.Универсальность и совместимость: Это мировой стандарт. Документы Word или таблицы Excel откроются на любом компьютере, а Windows поддерживает практически любое железо и софт.

2.Экосистема для работы: Все продукты (Windows, Office, Teams, OneDrive) бесшовно связаны между собой. Начали на смартфоне — продолжили на ПК, всё сохранилось само.

3.Безопасность и поддержка: Microsoft инвестирует миллиарды в кибербезопасность. Для бизнеса это самый надежный выбор с точки зрения защиты данных и долгосрочных обновлений.

Бонус: Для геймеров это Xbox Game Pass — самая выгодная подписка на игры, объединяющая консоли и компьютер.

Наши ПО

Microsoft Word — стандартный текстовый редактор, используемый для создания документов, отчетов и резюме.

Microsoft Excel — мощное приложение для работы с электронными таблицами, предназначенное для анализа данных, вычислений и создания сложных диаграмм.

Microsoft PowerPoint — программа для создания презентаций, используемая для подготовки визуальных слайд-презентаций для бизнеса, образования и творческих проектов.

Microsoft Teams — платформа для общения и совместной работы, объединяющая корпоративный чат, видеоконференции и хранилище файлов.

Microsoft Outlook — это менеджер личной информации, используемый в основном для электронной почты, но также включающий календарь, менеджер задач и органайзер контактов.

Билл Гейтс

Сооснователь компании, долгое время был её «лицом» и генеральным директором до 2000 года. Сейчас выступает в роли советника по технологиям и филантропа.

Стив Балмер

— Второй генеральный директор (2000–2014 гг.), известный своим экспрессивным стилем управления и расширением потребительских сервисов.

Сара Бонд

Президент Xbox. Руководит игровым направлением и развитием экосистемы Xbox.

Мустафа Сулейман

Генеральный директор подразделения Microsoft AI. Один из основателей DeepMind, присоединился к Microsoft в 2024 году для управления потребительскими продуктами на базе ИИ

Брэд Смит

Вице-председатель и Президент. Отвечает за юридические вопросы, кибербезопасность, экологическую устойчивость и отношения с государственными структурами.
